Summary
Three Chains, One Answer.(month one)
Week one put the server on Base, week two on Arbitrum and Ethereum. Agents now answer from the same read-only view of the protocol: positions, rates, backing, governance. The public beta stays on 6 November; the CLI moves one week, to week six, because the Parallel team asked for a dry run of the docs first.
