Incident
What Happened(52 minutes)
At 09:00 UTC the release build went live in both stores with the testnet RPC in its configuration. Balances showed as zero for every user who updated. No funds were at risk; 52 minutes of a wallet that looked empty, one hotfix, and a store review that was faster than we deserved.

Root cause
One configuration file for two environments
The testnet value had been committed for the beta and never reverted; the build did not know which environment it was for.
No check on the release build
The release checklist verified the version and the signing, not the network the app would talk to.
